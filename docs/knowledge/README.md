# OS Tutor 本地课程知识库

本目录保存 OS Tutor Agent 使用的稳定课程知识。它与六个实验工具的职责严格分开：知识库描述“正常情况下应当怎样理解”，工具结果描述“当前学生现场实际发生了什么”。当二者冲突时，当前工具证据优先，知识库不得被用来猜测学生代码、修改或运行状态。

当前 MVP 只包含 `labs/lab1/knowledge.json`。知识块按完整概念、流程或诊断问题组织，而不是按固定字符数机械切分。每块都包含来源、Lab、Stage、概念、相关文件、症状和提示等级等结构化 metadata。

## 提示等级

- Level 1：概念提示，帮助学生区分术语和证据边界。
- Level 2：方向提示，说明下一步应检查哪条机制链。
- Level 3：文件或位置提示，指出相关文件、符号或 Stage。
- Level 4：局部实现原理提示，只解释局部机制，不给出可复制实现。
- Level 5：答案级提示；学生检索链路禁止返回，本知识库不收录此类块。

默认检索只返回 Level 1～3，最多 5 个结果。知识文件不包含参考答案分支、教师材料路径或完整实现代码。

## 上下文标签

发送给模型时，本地检索内容使用 `[COURSE KNOWLEDGE]` 标签。六个工具返回的当前事实使用 `[RUNTIME EVIDENCE]` 标签。标签只供模型区分上下文，最终学生回答不显示内部标签。
