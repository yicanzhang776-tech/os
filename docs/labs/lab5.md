# Lab5：任务管理与协作式调度

## 实验简介

本实验引入任务抽象和协作式调度，让学生理解多个执行流如何共享 CPU。

## 学习目标

- 理解任务控制块、任务状态和任务上下文。
- 理解上下文切换与栈。
- 实现可观测的协作式调度流程。

## 前置知识

函数调用约定、栈、寄存器保存、Lab4 虚拟内存基础。

## 前置实验

Lab4：Sv39 虚拟内存。

## 涉及模块

规划模块为 `task`。具体目录、函数和汇编边界待 P0 架构确定后补充。

## 学生需要完成的任务

待 P0 架构确定后补充具体函数和 TODO 标记。

## Starter Code 边界

Starter code 应提供若干固定测试任务入口和日志约定，调度核心留给学生。

## 参考实现边界

参考实现只实现协作式调度，不实现抢占式时间片调度。

## 自动测试设计

规划中：测试任务按稳定顺序输出；调度结束后输出 `[lab5] PASS`。

## QEMU 预期输出

规划中，建议包含 `[lab5] start`、多个任务输出和 `[lab5] PASS`。

## 验收标准

- 多任务输出顺序稳定。
- 任务状态转换清楚。
- 无可运行任务时能明确结束。

## 常见错误

- 栈未对齐。
- 上下文保存不完整。
- 任务状态更新遗漏。
- 空任务队列导致死循环。

## 思考题

- 协作式调度和抢占式调度的区别是什么？
- 为什么上下文切换需要遵守调用约定？
