# Lab2：Trap 与异常处理

## 实验简介

本实验引入 RISC-V trap 机制，让学生观察异常进入内核后的处理流程。

## 学习目标

- 理解异常、中断和 trap 的基本区别。
- 理解 trap 入口、异常原因和异常返回。
- 能使用日志定位异常处理流程。

## 前置知识

RISC-V 特权级、控制状态寄存器、函数调用约定。

## 前置实验

Lab1：启动与 SBI 控制台。

## 涉及模块

规划模块为 `trap`。具体目录、函数和上下文结构待 P0 架构确定后补充。

## 学生需要完成的任务

待 P0 架构确定后补充具体函数和 TODO 标记。

## Starter Code 边界

Starter code 应能启动并触发一个可控异常，但 trap 处理主体留给学生完成。

## 参考实现边界

参考实现只覆盖基础异常处理，不实现系统调用和抢占式调度。

## 自动测试设计

规划中：触发固定异常，匹配异常日志和 `[lab2] PASS`。

## QEMU 预期输出

规划中，建议包含 `[lab2] start`、异常类型日志和 `[lab2] PASS`。

## 验收标准

- Lab1 功能保持可用。
- 能识别并处理指定异常。
- 未知异常有明确诊断输出。

## 常见错误

- trap 入口地址未正确设置。
- 异常返回地址处理错误。
- 把异常和中断原因混淆。

## 思考题

- 为什么系统调用也可以基于 trap 机制实现？
- 异常处理时为什么需要保存上下文？
