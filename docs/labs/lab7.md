# Lab7：设备与简化文件系统

## 实验简介

本实验引入设备和简化文件系统，把用户程序、系统调用和内核资源管理串起来。

## 学习目标

- 理解设备抽象和文件抽象。
- 理解文件描述符、读写和关闭。
- 能完成一个可测试的最小文件 I/O 场景。

## 前置知识

系统调用、用户程序、内存管理、错误处理。

## 前置实验

Lab6：用户态与系统调用。

## 涉及模块

规划模块为 `fs` 和 `drivers`。具体目录、设备类型和函数待 P0 架构确定后补充。

## 学生需要完成的任务

待 P0 架构确定后补充具体函数和 TODO 标记。

Starter code 应提供文件系统抽象接口和测试场景，核心读写逻辑留给学生。

## 自动测试设计

规划中：用户程序创建、写入、读取并校验内容，最终输出 `[lab7] PASS`。

## QEMU 预期输出

规划中，建议包含 `[lab7] start`、文件读写日志和 `[lab7] PASS`。

## 验收标准

- 文件打开、读写、关闭流程清晰。
- 错误文件描述符有明确处理。
- 用户态文件测试可重复运行。

## 常见错误

- 文件偏移未更新。
- 文件描述符表混乱。
- 用户缓冲区处理不安全。
- 把设备块大小和文件长度混淆。

## 思考题

- 为什么操作系统要把设备抽象成文件或类似文件的接口？
- 内存文件系统和块设备文件系统的教学取舍是什么？
