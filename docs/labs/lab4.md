# Lab4：Sv39 虚拟内存

## 实验简介

本实验引入 RISC-V Sv39 页表，让学生建立内核地址空间并理解虚拟地址翻译。

## 学习目标

- 理解页表项、权限位和多级页表。
- 理解 `satp` 和 TLB 刷新。
- 能解释虚拟地址到物理地址的翻译流程。

## 前置知识

RISC-V Sv39、页表、权限位、Lab3 物理页分配。

## 前置实验

Lab3：物理内存管理。

## 涉及模块

规划模块为 `memory` 的虚拟内存部分。具体目录、函数和映射策略待 P0 架构确定后补充。

## 学生需要完成的任务

待 P0 架构确定后补充具体函数和 TODO 标记。

## Starter Code 边界

Starter code 应提供页表项定义和测试框架，页表创建、映射和查询逻辑留给学生。

## 参考实现边界

参考实现只实现教学所需的最小内核地址空间，不引入用户地址空间。

## 自动测试设计

规划中：主机测试覆盖页表项权限和地址翻译；QEMU 测试确认启用分页后仍能输出 `[lab4] PASS`。

## QEMU 预期输出

规划中，建议包含 `[lab4] start`、分页启用日志和 `[lab4] PASS`。

## 验收标准

- 基础映射和查询正确。
- 启用分页后内核继续运行。
- 能解释关键权限位含义。

## 常见错误

- 页表页未清零。
- 漏掉有效位。
- 启用分页后未刷新 TLB。
- 映射范围覆盖设备或固件区域。

## 思考题

- 为什么虚拟内存是用户态隔离的基础？
- 内核地址空间应当如何保护自身代码段？
