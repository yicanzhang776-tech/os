# Lab3：物理内存管理

## 实验简介

本实验引入物理页管理，让学生实现最小可测试的物理内存分配能力。

## 学习目标

- 理解物理地址、页和页号。
- 理解内核镜像之外的可用内存范围。
- 掌握用主机单元测试验证纯逻辑模块的方法。

## 前置知识

内存布局、页大小、Rust 所有权基础。

## 前置实验

Lab2：Trap 与异常处理。

## 涉及模块

规划模块为 `memory` 的物理内存管理部分。具体目录和函数待 P0 架构确定后补充。

## 学生需要完成的任务

待 P0 架构确定后补充具体函数和 TODO 标记。

## Starter Code 边界

Starter code 应提供地址类型和测试样例框架，核心分配逻辑留给学生。

## 参考实现边界

参考实现只实现物理页分配与回收，不启用虚拟内存。

## 自动测试设计

规划中：主机单元测试覆盖地址取整、分配、释放、耗尽和复用；QEMU 测试输出 `[lab3] PASS`。

## QEMU 预期输出

规划中，建议包含 `[lab3] start`、物理页统计和 `[lab3] PASS`。

## 验收标准

- 地址计算正确。
- 页分配和释放可重复。
- 不把内核镜像区域加入可分配页。

## 常见错误

- 页号上下取整 off-by-one。
- 重复释放同一页。
- 忽略内核镜像结束地址。

## 思考题

- `FrameTracker` 这类设计如何帮助减少资源泄漏？
