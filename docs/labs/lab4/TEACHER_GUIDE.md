# Lab4 教师指南

## 课程定位

Lab4 是从“能分配物理页”进入“能管理虚拟地址空间”的关键实验。建议放在讲完 RISC-V 特权级、页表和地址翻译之后。

建议课时：2 次课或 1 次课加 1 次实验课。

## 课堂讲授重点

- Sv39 地址如何拆成 3 级 VPN。
- PTE 中 PPN 和 flags 的位置。
- 叶子 PTE 与中间级 PTE 的区别。
- 为什么 `satp` 必须配合 `sfence.vma`。
- 为什么第一版采用恒等映射，而不是高地址内核映射。

## 三个任务的验收方法

| 任务 | 验收命令 | 重点观察 |
|---|---|---|
| 任务一 | `scripts/test-lab4.ps1 -Stage 1` | 是否输出 `[Lab4-T1] PASS` |
| 任务二 | `scripts/test-lab4.ps1 -Stage 2` | 是否输出 `[Lab4-T2] PASS`，并能处理重复映射 |
| 任务三 | `scripts/test-lab4.ps1 -Stage 3` | 是否输出 `satp activated`、`paging is active` 和 `[Lab4] PASS` |

## 学生容易卡住的位置

- VPN 索引顺序：数组中可以保存 `[VPN0, VPN1, VPN2]`，但页表遍历要从 `VPN2` 开始。
- `ceil` 的边界条件：已经对齐时不能多加一页。
- 中间级页表 PTE 只设置 `V`，叶子 PTE 才设置 `R/W/X`。
- 写入 `satp` 后立刻崩溃，通常是当前代码或栈没有被恒等映射。

## 如何演示

1. 先在 `lab4-starter` 运行 `scripts/test-lab4.ps1 -ExpectIncomplete`，展示 starter 正常但未完成。
2. 切到 `lab4-solution`，运行 Stage 1、Stage 2、Stage 3。
3. 展示 `SOLUTION.md` 中的权限表，强调没有把所有内存统一映射成 RWX。

## 判断是否直接复制答案

可以要求学生解释：

- 为什么 `map` 遇到已有效 PTE 要返回错误。
- 为什么 `satp = (8 << 60) | root_ppn`。
- 为什么启用分页前必须映射当前执行代码和栈。
- 固定容量页表页数组的限制是什么。

如果学生能独立解释这些点，通常说明理解程度较好。

## 可选扩展任务

- 增加只读页写入异常观察。
- 尝试高地址内核映射。
- 将固定容量页表页数组改为后续堆分配器管理。
- 增加用户态 `U` 权限映射，为 Lab6 做准备。

- 任务一：25%
- 任务二：35%
- 任务三：30%

评分时建议把“能解释实现边界”纳入代码可读性部分，避免学生只追求通过测试。
