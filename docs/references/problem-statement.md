# 赛题说明整理

本文档整理 OS 功能挑战赛道第 20 题的公开题目信息。内容来自项目成员提供的官方页面截图和公开链接，仅用于项目内部设计与验收对齐。

## 基本信息

- 比赛：2026 年全国大学生计算机系统能力大赛。
- 赛项：操作系统设计赛。
- 赛道：OS 功能挑战赛道。
- 题号：第 20 题。
- 题目中文名：AI 合作的操作系统教学实验环境。
- 题目英文名：AI-assisted Operating System Teaching Experimental Environment。
- 难度等级：B。
- 题目类型：教学型。

## 任务理解

题目要求学生与 AI 合作，参考较新的操作系统教学实验、课程资料和参考实现，设计一套适合本科生自学和教师教学的操作系统内核教学实验环境。

本项目的实现目标包括：

- 基于 Rust 开发操作系统内核教学环境。
- 面向 RISC-V 64 架构。
- 能够在 QEMU 模拟器中启动和运行。
- 设计至少 5 个基础实验；本项目规划 7 个递进式实验。
- 通过 Rust crate 或 workspace 组织可复用模块。
- 为内核主体、执行程序或内核模块提供单元测试或系统测试。
- 文档使用 Markdown。
- 架构图、流程图和依赖图优先使用 Mermaid。

## 当前项目解释

P0 是工程运行基线，不计入正式教学实验。Lab1 到 Lab7 才是正式教学实验。

P0 只负责证明工程链路可重复运行：

- Rust 裸机工程能够编译。
- 目标架构为 `riscv64gc-unknown-none-elf`。
- 能够在 QEMU `virt` 机器上运行。
- 使用 OpenSBI 进入 S-mode 内核。
- 内核能够输出 `[P0] PASS`。
- 提供可重复执行的构建、运行和测试命令。
