# 参考资料截图归档说明

本目录用于保存官方公开资料的脱敏截图。

## 允许保存

- 公开题目说明。
- 公开评分标准。
- 公开提交要求。
- 公开环境配置说明。

## 禁止保存

- 账号名称、邮箱、手机号、学号等个人信息。
- 浏览器登录状态、头像、通知信息。
- Token、密码、Cookie、私有仓库地址。
- 与比赛无关的个人标签页或桌面信息。

## 命名建议

```text
problem-statement-YYYYMMDD.png
scoring-YYYYMMDD.png
submission-rules-YYYYMMDD.png
environment-YYYYMMDD.png
```

保存截图前必须由项目成员人工确认已脱敏。
