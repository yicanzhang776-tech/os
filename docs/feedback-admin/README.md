# 教学反馈与运行记录管理

该工具用于项目负责人接收学生自愿提交的教学反馈和脱敏运行记录，并在本机查看、筛选和导出。它与 AI 教学助教、教师评分是三条独立链路。

## 端口与职责

- `127.0.0.1:8890`：反馈接收服务。接收 `os-demo.feedback.submit/v1` 和 `os-demo.run.submit/v1`，执行协议、大小、邀请码、频率与二次脱敏校验。
- `127.0.0.1:8891`：教师本机管理页。只绑定回环地址，提供筛选、统计以及 JSON/CSV/Markdown 导出。
- 公网 HTTPS 入口应由项目负责人配置的反向代理终止 TLS，再转发到 8890；8891 不应暴露到公网。

## 数据文件

接收端分别追加写入反馈 JSONL 与运行记录 JSONL。文件属于教师本机数据，不应提交到 Git。每行是一条独立 JSON 记录，损坏行在管理页读取时会被跳过并报告，不覆盖其他记录。

邀请码只用于降低误提交和普通滥用风险，不是学生身份认证，也不能替代 HTTPS、访问控制、速率限制和服务器日志管理。请定期备份 JSONL，并将备份放在受控位置。

## 推荐课堂流程

1. 教师通过 HTTPS 发布接收地址和一次性或阶段性邀请码。
2. 学生在可视化页面预览将发送与排除的字段。
3. 学生主动勾选同意后提交教学反馈或脱敏运行记录。
4. 教师在 8891 管理页按 Lab、角色、日期和结果筛选。
5. 教师导出汇总用于教学改进；运行记录如需评分，导入本地教师评分页并人工复核。

## 隐私与备份

反馈文本仍可能由学生主动填写个人信息；运行记录已排除完整源码、完整终端日志、本机路径和访问令牌，但公开分享前仍须人工检查与脱敏。管理页导出文件、JSONL 备份和邀请码不得进入公开仓库。
